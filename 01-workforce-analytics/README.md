# Contact Centre Workforce Analytics Dashboard

## Project Overview

This project analyses fictional contact centre operational data to evaluate call demand, forecasting accuracy, service level performance and staffing requirements.

The objective is to develop an interactive Power BI dashboard and identify actionable insights to support workforce planning.

## Business Questions

1. How accurately does forecasted call volume match actual demand?
2. Which days and time intervals experience the highest call volumes?
3. How do service levels change during periods of high demand?
4. When does actual staffing fall below planned staffing?
5. What operational improvements could support better workforce planning?

## Key Performance Indicators

- Forecasted vs actual call volume
- Forecast accuracy (WAPE)
- Average Handle Time (AHT)
- Service Level (%)
- Abandonment Rate (%)
- Planned vs actual staffing

## Tools

- Microsoft Excel
- SQL
- Power BI

## Dataset

A synthetic contact centre dataset will be created for this project. No confidential employer or customer data will be used.
