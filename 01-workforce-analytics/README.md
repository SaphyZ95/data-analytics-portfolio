
# Contact Centre Workforce Analytics

## Project Overview

This project explores contact centre workforce performance using data analytics and business intelligence tools.

The aim is to analyse call volumes, forecast accuracy, service levels and staffing requirements to identify operational trends and potential improvements.

## Business Objectives

- Analyse daily and hourly call volumes.
- Compare forecasted and actual call volumes.
- Evaluate service level performance.
- Identify periods of potential understaffing and overstaffing.
- Develop insights to support workforce planning decisions.

## Tools and Technologies

- Power BI
- SQL
- Microsoft Excel

## Dataset

A fictional contact centre dataset will be developed for this project.

## Project Methodology

1. Data preparation and cleaning.
2. Exploratory data analysis.
3. SQL-based analysis.
4. Power BI dashboard development.
5. Business insights and recommendations.
